Start here: your WilsonWorks finance team

This folder is a finance team you talk to in plain English. Hal closes the books, Imani watches cash, Nadia does budgets and forecasts, Anya answers tax questions, Elle gives the big picture, and Soph tells you who to ask.

It comes with a practice business, Harbor Lane Coffee. It is made up, so you can try everything without touching a real client. This page takes you from installing the app to your first answer, in about 15 minutes.

One rule: never type client names or client details into a chat in this folder. Practice on Harbor Lane Coffee.
You need: a paid Claude plan (Pro, Max, Team or Enterprise). The Code tab used below is part of those plans.

Install and get your first answer

  1. Download the Claude desktop app.
    Mac: Download for macOS. Windows: Download for Windows. Both are also on claude.com/download.
    You should see: a file in your Downloads folder (Mac: ends in .dmg; Windows: ends in .exe).
  2. Install it.
    Mac: double-click the .dmg and drag Claude into Applications. Windows: double-click the setup file and follow the prompts.
    You should see: Claude in your Applications folder (Mac) or Start menu (Windows).
  3. Open Claude and sign in with your Claude account.
    You should see: the Claude home screen with a box to type in.
  4. Unzip the kit into your Documents folder.
    Mac: double-click WilsonWorks-Finance-Kit.zip, then drag the new folder into Documents. Windows: right-click the zip, choose Extract All…, and pick Documents.
    You should see: a folder Documents/WilsonWorks-Finance-Kit holding this page, a sample-company folder and an outputs folder.
  5. In Claude, click the Code tab at the top of the sidebar. (If the tabs show only icons, hover to see the names.)
    You should see: a prompt box with a row of small controls under it. If it asks you to upgrade, your plan doesn't include the Code tab yet.
  6. In the row under the prompt box, click the first control and choose the top entry under Local.
    You should see: "Local" (or your computer's name) in that first control.
  7. Click the folder control next to it, choose Open folder…, go to Documents, select WilsonWorks-Finance-Kit and click Open.
    You should see: WilsonWorks-Finance-Kit named in that row.
  8. Type this and press Enter:
    Hal, walk me through closing last month for the sample company.
    You should see: Claude hand the question to Hal and start reading the files in sample-company.
  9. If Claude asks permission to read a file or save one, click Allow. It only works inside this folder.
    You should see: the work carry on after each Allow.
  10. Read Hal's answer. It takes a few minutes.
    A good answer: Hal closes September 2026 (the only month in the practice files), checks the bank statement against the books, and names three things to fix:
    • a $640 deposit on September 18 with no invoice and no card payout behind it,
    • a $186.43 Amazon purchase with no category,
    • a $412 espresso machine repair with no receipt.
    He asks you what to do about each one before going further, and saves a close packet in outputs. If one of the three is missing, ask him: Hal, did anything not match?
On a Mac: if a box asks to install command line developer tools (or mentions python3), click Install and let it finish. It is only needed for the team's message board, which is optional; everything above works without it.
On Windows: if Claude says "Git is required", update the app (Help, then Check for Updates). If it still asks, install Git for Windows and try again.

  2. Lila: Lila, who owes the sample company money, and is anyone late?

  6. Nadia: Nadia, why was September's profit higher than August's?
  7. Nadia: Nadia, if card sales drop 15% next month, what happens to profit?
  8. Anya: Anya, how long should a small business keep its receipts?
  9. Elle: Elle, how is the sample company doing, in three lines?
  10. Soph: Soph, a customer is paying late. Who should I ask?

About QuickBooks

This kit has no QuickBooks connection. Don't add one for a client's books. The team works from files you export, like the ones in the sample-company folder.

If you have already connected QuickBooks to your own Claude account (in Claude's Settings, under Connectors), the team can use that connection, and this kit can't stop it. Check there before you work on a client's files, and disconnect QuickBooks if it is listed.
