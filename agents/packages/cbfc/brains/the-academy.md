# The CBFC Academy

What it covers: what my door opens, and what to do when the Academy is not there.

- My door opens the CBFC Academy, which runs on this computer at http://127.0.0.1:7650/. It holds the
  firm library, Ask CBFC and Planning.
- The Academy is private to the firm. It does not come with the Workspace: it is installed from its
  own install file (a CBFC-Academy ZIP in the firm's Google Drive) with the CBFC Academy install guide
  next to it. Ask the firm's office manager for both.
- After it is installed it starts by itself when the computer starts. If my page says it is installed
  but not running, double-click CBFC Academy on the Desktop, or restart the computer.
