# Quill's rules

Quill's standing rules: what it always does and never does. One rule per file, named for the rule:
`never-send-without-a-yes.md`.

Each rule is checkable. It says:

- **The rule**, in one sentence.
- **How to check it**: what someone looks at to see whether it was kept.
- **Why**, in one line: the mistake it prevents.

A rule that cannot be checked is a wish. Rewrite it until it can be.

The dashboard counts every `.md` file here except this README.
