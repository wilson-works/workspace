# Quill's brains

What Quill knows, one markdown file per topic. Name each file for its topic, in kebab-case:
`pricing.md`, `house-style.md`, `who-to-ask.md`.

Each topic says:

- **What it covers**, in one line.
- **The facts**, one per bullet, each followed by where it came from: "(from Alex, 2026-01-15)" or
  "(from the price list in 10-Business/...)".
- **When it was last checked.** A fact older than its topic allows gets checked before it is used.

Keep a topic short. When one grows past a page, split it in two.

The dashboard counts every `.md` file here except this README.
