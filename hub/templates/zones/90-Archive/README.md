# 90-Archive

**What goes here:** cold storage. Finished projects, old exports, past years. Read from it; do not work in it.
`_DumpQueue/` holds what is waiting for a yes before it is deleted. Nothing in it is destroyed until someone has looked.

**What never goes here:** work in progress, and anything that has not been copied and checked before its original
is removed.

**Example:** `90-Archive/2025-garden-planner-v1/`.
