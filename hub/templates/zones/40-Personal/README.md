# 40-Personal

**What goes here:** personal documents and media. When more than one person uses this computer, give each person a
folder: `40-Personal/Alex/`.

**What never goes here:** business or client documents (they go in `10-Business/`), and anything belonging to a person
whose folder is on the off-limits list in the Hub's CLAUDE.md.

**Example:** `40-Personal/Alex/Medical/2026-09-14-checkup.pdf`.
