# 10-Business

**What goes here:** one folder per company or client, named in PascalCase (`10-Business/GreenThumb/`), holding its
documents: contracts, invoices, plans, exports, notes.

**What never goes here:** code (that goes in `{{code_zone}}/`), media masters (those go in `30-Media/<Company>/`), and
personal papers (those go in `40-Personal/`).

**Example:** `10-Business/GreenThumb/Contracts/2026-10-01-supplier-agreement.pdf`.

Each company folder shows up in `NAV.md` by itself the next time `hub nav` runs.
