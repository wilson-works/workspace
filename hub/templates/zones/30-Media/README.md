# 30-Media

**What goes here:** photos, video, music and brand files. Company media goes in `30-Media/<Company>/`, split into
`Events/`, `Shoots/`, `Brand/` and `Posts/`. New media lands in `_Ingest/` first and is sorted from there.

**What never goes here:** documents (they go in `10-Business/` or `40-Personal/`) and code.

**Example:** `30-Media/GreenThumb/Shoots/2026-10-02-spring-catalog/`.

If a folder here is the only copy of something you cannot replace, back it up before anything else.
